## Generation policy and quality boundaries

UI jobs use native `thpt.Orchestrator`, not `/v2` generic orchestration. Composer sections may run concurrently but are flattened in matrix order. Illustrator is invoked even with an empty request list in the THPT path; V-ACT skips empty drawing chunks. Solver receives student views with answer-bearing fields removed (`thpt/rendering.py:10`, `vact/rendering.py:9`). Reviewer runs only once. One feedback revision may recompose/reillustrate/resolve; it is not reviewed again (`thpt/orchestrator.py:174-288`). A completed run means pending human review, not accepted quality.

Non-reviewer provider transport has one transient retry (`thpt/runtime.py:29`); schema repair has up to two attempts (`thpt/agents.py:95`). These multiply possible model calls; idempotent job creation does not make upstream inference exactly once. Reviewer has no retry. Targeted UI regeneration does not use the same RecordingProvider wrapper as full generation, so trace/metrics coverage differs.

Labels NB/TH/VD/VDC describe cognitive objectives; generic easy/medium/hard are separate labels. `core/validation.py:208` explicitly leaves correctness, difficulty calibration, semantic duplicates and realistic time to human/semantic review. Pipeline validation does not provide psychometric calibration or a measured exam accuracy guarantee.

Persistent cost reservations exist when settings enable them (`providers/budget.py:14/:48`), with unknown calls retaining reservation. Per-role call summaries use repository price estimates (`thpt/metrics.py:14`), not provider billing or project quota. This audit did not verify current public prices or account quota.
