# Provincial exams, ngu-van, 2025-2026 school year (thi thử tốt nghiệp THPT 2026)

Downloaded 2026-10-29 with the owner's approval from thuvienhoclieu.com (a document site; Word copies, NOT the originals issued by the Sở GD&ĐT). One folder per paper: paper.docx and source.json (file URL, SHA-256, size, embedded image count). manifest.csv lists every attempt, including failures.

Formulas in these Word files are MathType pictures (embedded .bin with .wmf previews), not Word equations: convert to pdf with LibreOffice before OCR. Each file is usually the exam, an answer key and worked solutions together. Internal evidence only; the repo stays private and nothing here ships in the product.
