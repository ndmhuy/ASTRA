Câu 3. Xét hàm tìm kiếm sau:

| Python | C++ |
| :--- | :--- |
| `def check(a, n, k):` | `bool check(int a[], int n, int k) {` |
| `    res = False` | `    bool res = false;` |
| `    for i in range(n):` | `    for (int i = 0; i < n; i++) {` |
| `        if a[i] > k:` | `        if (a[i] > k) {` |
| `            res = True` | `            res = true;` |
| `            break` | `            break;` |
| `    return res` | `        }` |
| | `    }` |
| | `    Return res;` |
| | `}` |

b) Hàm trên thực hiện thuật toán tìm kiếm tuần tự để kiểm tra xem trong mảng có phần tử nào lớn hơn $k$ hay không.
c) Nếu mảng $a = \{1, 3, 5, 7\}$ và $k = 10$, hàm sẽ trả về giá trị True.
d) Thuật toán này sử dụng cấu trúc dữ liệu ngăn xếp (Stack) để quản lý việc lặp.
